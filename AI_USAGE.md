# AI Usage Documentation

## Project Name

FocusBoard – Task Management Dashboard

## AI Tool Used

ChatGPT

## Purpose of Using AI

ChatGPT was used as a development assistant during the implementation of the FocusBoard project.

The purpose was to understand React concepts, receive implementation guidance, troubleshoot errors, and improve the overall project structure.

## Areas Where AI Assistance Was Used

### 1. React Functionality
- Assistance with React useState and useEffect.
- Guidance for implementing task creation, editing, and deletion.
- Assistance with search and filtering functionality.
- Guidance for calculating dashboard statistics.

### 2. Data Persistence
- Assistance with implementing browser localStorage.
- Guidance for saving and restoring task information after refreshing the page.

### 3. Debugging and Documentation
- Assistance with identifying and fixing implementation issues.
- Guidance for preparing project documentation.
- Suggestions for manually testing application features.

## Human Contribution

The project was implemented and tested by the developer with AI assistance.

The developer:
- Created and managed the project in Visual Studio Code.
- Followed the implementation steps.
- Added and updated the provided code.
- Ran the application locally.
- Tested the implemented functionality.
- Checked responsive behavior across different screen sizes.
- Reviewed the application output and confirmed the working features.

## AI Usage Transparency

AI was used as a supporting development tool. The project was reviewed and tested by the developer to verify that the implemented features worked as expected.
